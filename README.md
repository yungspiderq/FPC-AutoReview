# 🌟 AutoReview — автоматические отзывы покупателям

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

**Автор:** yungspider

После успешной выдачи товара автоматически оставляет покупателю отзыв с оценкой
через штатный метод FunPay `send_review`. Отзывы повышают доверие к магазину,
поднимают рейтинг и стимулируют покупателей отвечать взаимностью.

## Возможности

- 🌟 **Авто-отзыв после выдачи** — не мгновенно, а через настраиваемую задержку
  (по умолчанию 30 минут, диапазон 1 мин — 3 суток), когда покупатель успел проверить товар.
- 🔥 **Оценка 1–5** (по умолчанию 5) и **шаблон текста** с переменными
  `$username` (ник), `$lot` (название лота), `$order` (номер заказа).
- ⛔ **Чёрный список покупателей** — кому отзыв оставлять не нужно (по нику или ID).
  Список проверяется и при постановке в очередь, и непосредственно перед отправкой.
- 📮 **Очередь и история отзывов хранятся на диске** — переживают рестарт Кардинала.
- Каждому заказу — **не более одного** отзыва. Ошибки ретраятся (до 3 попыток),
  «протухшие» записи (старше 7 дней) удаляются без отправки.
- 🧪 Кнопка **«Тест»** — посмотреть, как будет выглядеть отзыв.
- Отзывы отправляются штатным методом FunPay и видны в карточке заказа.

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-AutoReview/main/auto_review.py -O plugins/auto_review.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

Команда **`/review`** (или `⚙️ Настройки` на странице плагина):

| Кнопка | Действие |
|---|---|
| 🟢/🔴 Включено | Включить/выключить авто-отзывы |
| ⏱ Задержка: 30 мин. | Через сколько минут после выдачи оставлять отзыв (1–4320) |
| 🔥 Оценка: 5 ⭐ | Оценка покупателю (1–5) |
| 📝 Текст отзыва | Редактировать шаблон (`$username`, `$lot`, `$order`) |
| ⛔ Чёрный список | Добавить/убрать покупателя (ник или ID; `-ник` — удалить) |
| 🧪 Тест (предпросмотр) | Прислать пример отзыва вам в Telegram |

В меню видно, сколько заказов в очереди и сколько отзывов уже оставлено.

### Шаблон по умолчанию

```
Спасибо за покупку лота «$lot», $username! Всё на высшем уровне —
моментальная оплата, отличный покупатель. Рекомендую! ⭐
```

> Совет: не оставляйте отзыв мгновенно — небольшая задержка выглядит естественнее.
> В связке с [FPC-RegularsDetector](https://github.com/yungspiderq/FPC-RegularsDetector)
> можно благодарить постоянных покупателей по-особенному.

## Важно знать

- Отзыв оставляется только после **успешной автовыдачи** (событие POST_DELIVERY
  с флагом `delivered`). На ручные продажи без автовыдачи не срабатывает.
- FunPay позволяет оставить/отредактировать отзыв по заказу; если заказ ещё не в
  состоянии «можно оставить отзыв», попытка будет повторена (до 3 раз).
- История отзывов ограничена 500 последними записями.
- Настройки и очередь: `storage/plugins/auto_review/settings.json`.

## Состав репозитория

- `auto_review.py` — плагин (класть в `plugins/`).
- `tests_plugin_auto_review.py` — тесты (49 проверок на моках: очередь, задержки,
  ретраи, протухшие записи, чёрный список, оценка, история, весь Telegram-UI, настройки).
  Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_auto_review.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_auto_review.py
  ```
